# NEXORA — Social Platform UI

A responsive social-media dashboard concept built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and sample feed
- `style.css` — responsive design and visual styling
- `script.js` — demo interactions (likes, comments, search, follow buttons, post composer)

## Run locally
Open `index.html` in a browser. No build tools are required.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `nexora-social`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then save.
6. Wait for GitHub to publish the site and open the URL shown in Pages settings.

## Important
This is a front-end demo. Posts are only added to the current page and are not saved permanently. Authentication, real accounts, persistent posts, real media uploads, notifications, messaging and live comments require a backend/database and appropriate security rules. Replace `hello@example.com` with your own contact email. Google Fonts require an internet connection; fallback fonts are included.
